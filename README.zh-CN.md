# Anew

**[English](README.md) | 简体中文**

> **One small loop a day.**

Anew 是一个面向 ADHD 友好体验的移动端每日计划应用，核心目标是：**减少开始一件事之前所需要做的决定。**

与其让用户一次面对一整张任务清单并不断比较优先级，Anew **一次只呈现一个候选任务**，将计划过程转化为一系列简单的选择：**今天不做**，或**今天保留**。通过缩小每一次需要面对的选择范围，滑动交互减少了任务之间的反复比较，让用户更容易从“计划”进入“行动”。

**选择 → 专注 → 完成 → 复盘**

---

## 为什么是 Anew

传统待办清单往往一次呈现所有事情。在真正开始行动之前，用户可能已经需要比较优先级、判断任务难度，并决定究竟应该先做什么。

Anew 从一个更简单的问题出发：

> **如何减少开始一件事所需要做的决定？**

与其继续增加更多计划和排序工具，Anew 将整个体验收窄成一系列小的选择，以及一个轻量的每日循环。

## 核心交互

### 用滑动完成选择

候选任务会**一次只出现一个**。

- **左滑**或点击**今天不做**，暂时跳过这个任务。
- **右滑**或点击**今天保留**，将任务加入今天的计划。

当天跳过的任务会离开当前任务卡组，并在第二天重新回到候选任务中。

这样，一次需要比较多个选项的计划问题，被转化成一系列简单的二元选择。

## 每日循环

### 选择 Pick

通过滑动卡片选择今天要做的任务，也可以使用 Quick Add 快速添加自己的任务。

其中一个任务可以被设为当天的 **One Big Thing**。

### 专注 Focus

一次专注于一个已经选择的任务。

Focus 提供：

- 可逐项勾选的任务步骤
- 任务切换
- 可选倒计时
- 15 / 25 / 45 分钟预设
- 自定义计时时长
- 长时间专注时的轻量提醒

### 完成 Done

可以直接从 Today 或 Focus 完成任务，并查看当天的完成进度。

### 复盘 Review

通过对话式 Review 回顾当天的状态。

复盘内容可以结合当前计划信息生成新的候选任务，用于下一轮计划。

在浏览器支持的情况下，也可以通过语音输入 Review 内容。

- 一次一个任务的滑动式计划
- **今天保留 / 今天不做**二元选择
- Today 当日计划与完成进度
- **One Big Thing** 重点任务
- Quick Add 快速添加
- 可编辑的 Daily Basics
- 可逐项完成的任务步骤

## 设计原则

**一次只做一个决定**  
通过减少任务之间的比较，而不是增加更多优先级工具来降低决策负担。

**行动优先于完美规划**  
重点是帮助用户开始并继续行动，而不是建立一个完美的任务管理系统。

**结构是可选的**  
计时器、任务步骤、Daily Basics 和 AI 辅助都可以按需使用，而不是强制进入每一个任务流程。

**平静的移动端体验**  
围绕专注、轻量的移动端流程设计，而不是构建信息密集的效率仪表盘。

**本地优先的数据方式**  
核心计划数据保存在用户自己的浏览器中。只有在用户主动导出数据，或使用配置好的 AI 功能时，相关内容才会离开本地流程。

## AI 功能

Anew 当前包含两个服务端 AI 流程：

- **Review 对话** — 根据用户当天的复盘内容进行回应
- **候选任务生成** — 根据 Review 和当前计划信息生成新的候选任务

项目支持 `mock`、OpenAI 和 Anthropic 三种 provider。

`mock` 模式不需要 API Key；使用 OpenAI 或 Anthropic 时，需要配置自己的 provider 凭证。

API Key 只由服务端 API Routes 读取，不应暴露到浏览器。

## 本地运行

```bash
npm install
cp .env.example .env.local
npm run dev
```

如果只需要在本地体验而不调用真实 AI，可以设置：

```env
AI_PROVIDER=mock
```

然后访问：

```text
http://localhost:3000
```

如果需要在同一局域网内的手机上测试：

```bash
npm run dev:lan
```


## 当前限制

Anew 目前是一个 local-first MVP。

- 数据分别保存在当前浏览器和设备中。
- 暂未实现账户和登录系统。
- 暂不支持跨设备或云端同步。
- Review 暂未提供长期历史复盘档案。
- 部分运行时生成内容尚未完全完成简体中文本地化。
- 语音输入取决于浏览器支持情况。
- 已提供添加到手机主屏幕所需的 Web App 配置，但暂未实现离线 Service Worker。
- 完整 AI 功能需要能够运行 Next.js API Routes 的部署环境。

## 安全说明

API 凭证必须保留在服务端。不要提交 `.env.local`，也不要通过 `NEXT_PUBLIC_` 环境变量暴露 provider API Key。
