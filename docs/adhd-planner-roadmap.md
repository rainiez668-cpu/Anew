# Anew Roadmap

Anew is a general ADHD-friendly daily planning app. This roadmap focuses on preserving the calm core loop while gradually improving planning, focus, and reflection.

## Guiding principles

- Keep the daily loop small: **Pick → Focus → Done → Review**.
- Prefer fewer choices over more controls.
- Keep skipped or unfinished tasks shame-free.
- Preserve local-first behavior and data portability.
- Make AI helpful but optional.

## Current MVP

- Today / Focus / Review information architecture.
- Swipe-based daily task selection.
- Daily basics checklist.
- One big thing plus smaller supporting tasks.
- Optional focus timer.
- Review conversation and tomorrow task generation.
- Mock / OpenAI / Anthropic AI provider adapter.
- Local JSON export and import.
- English and Simplified Chinese UI.
- PWA-ready metadata.

## Near-term improvements

- Refine empty states and onboarding copy.
- Add a task breakdown assistant for large tasks.
- Improve accessibility labels and keyboard/screen-reader coverage.
- Add no-shame weekly momentum summaries.
- Continue polishing bilingual typography and localization coverage.

## Later improvements

- Optional hosted sync.
- Accounts and cross-device backup.
- Gentle reminders.
- Offline resilience improvements.
- More configurable daily planning preferences.

## Out of scope for the current MVP

- Multi-user collaboration.
- Social feeds.
- Complex project management.
- Public task sharing.
- Calendar ownership or full calendar replacement.
